# SAF Avenue

Сайт: [kolokolchi.github.io/SAF_Landing](https://kolokolchi.github.io/SAF_Landing/). Репозиторий: [Kolokolchi/SAF_Landing](https://github.com/Kolokolchi/SAF_Landing).

## Публикация

Изменения в ветке `main` автоматически собираются и публикуются в GitHub Pages через `.github/workflows/pages.yml`. Публикуется только содержимое `dist/`; исходники сервера, инструменты разработки и сохранённые контакты не входят в сайт.

Сборка для адреса проекта:

```sh
npm run build -- --base /SAF_Landing/ --static
```

Сборщик подставляет префикс проекта в пути к ресурсам и страницам. GitHub Pages раздаёт статические файлы и не запускает Node-сервер: на опубликованной версии форма предлагает связаться через имеющуюся ссылку WhatsApp. Для сохранения заявок через `/api/leads` нужен серверный хостинг или собственный обработчик.

Локальная копия [saf.sensata.kz/avenue](https://saf.sensata.kz/avenue), сохранённая 30 сентября 2026 года. Используется исходная верстка Tilda: размеры и расположение блоков, адаптивные настройки, оригинальные шрифты, изображения, анимации, меню, слайдеры и всплывающие окна.

## Запуск

Требуется Node.js 18 или новее. Менеджер пакетов — npm; версии закреплены в `package-lock.json`.

```sh
npm ci
npm run dev
```

Открыть http://localhost:5173/avenue. Дополнительные страницы: `/avenuekz`, `/privacy` и `/privacykz`. `/` также открывает русскую версию Avenue.

Другой порт:

```sh
npm run dev -- --port 8080
```

## Agentation для разработки

Проект поддерживает [Agentation](https://github.com/benjitaylor/agentation) для уточнения запросов к кодовым агентам. В настольном браузере нажмите плавающую панель, выберите элемент страницы, добавьте комментарий и скопируйте структурированную обратную связь в запрос к Codex. Вывод включает селекторы и контекст элемента, чтобы точнее указать нужную правку.

Панель автоматически подключается ко всем страницам при `npm run dev` (`--dev`) или `NODE_ENV=development`. `server.mjs` добавляет скрипт в HTTP-ответ, а `scripts/agentation-entry.jsx` монтирует `<Agentation />` в отдельный React-контейнер. Agentation, React, React DOM и esbuild установлены исключительно в `devDependencies`; код панели собирается в памяти и не записывается в `assets/` или `dist/`.

`npm start` по умолчанию работает без панели. Явный `NODE_ENV=production` отключает её даже при `--dev`: сервер не импортирует сборщик и не раздаёт `/__dev/agentation.js`. Статическая сборка `npm run build` также не содержит Agentation. Для обычного запуска и статической сборки достаточно `npm ci --omit=dev`. После изменения кода панели перезапустите dev-сервер.

Для текущего процесса используется копирование обратной связи; подключение внешнего MCP-сервера отдельно не настроено.

## Состав

- `index.html`, `avenue.html` — русская версия.
- `avenuekz.html` — казахская версия.
- `privacy.html` — политика конфиденциальности оригинала.
- `privacykz.html` — оригинальная казахская версия политики конфиденциальности.
- `assets/` — локальные оригинальные изображения, шрифты, стили, скрипты и оба PDF-буклета.
- `assets/images/avenue-panorama.png` — панорама комплекса с высоты, выделенная отдельно для замены. Этот файл используется в странице; его размер 1672 × 941 пикселей.
- `assets/images/avenue-facade-realistic.png` — обновлённый рендер фасадов в блоке «Олицетворение статуса», созданный встроенным image_gen с исходным изображением и главным баннером сайта как референсами. Оригинальный `C_0262_2.jpg` сохранён; манифест использует новую версию при повторном обновлении копии. Запрос генерации: `scripts/image-prompts/avenue-facade.txt`.
- `local-runtime.js` — сохранение заявок в копии, кнопка внешнего каталога и повторяемое появление элементов при прокрутке.
- `server.mjs` — сервер и локальный обработчик заявок.
- `asset-manifest.json` — соответствие исходных URL сохранённым ресурсам.
- `source.html` — исходная публичная страница для сверки.
- `scripts/mirror.py` — повторное получение публичных страниц и материалов.

Внешние ссылки WhatsApp, соцсети, 2GIS и видео YouTube сохранены. Каталог доступности Profitbase открывается во встроенном окне и требует доступа к внешнему сервису; его данные и серверная часть не входят в копию. Оболочка плавающей кнопки и её оригинальная иконка сохранены локально, поэтому кнопка отображается независимо от загрузки Profitbase.

Формы сохраняют контакты в `data/leads.jsonl` и показывают сообщение о локальном сохранении. Отправка в CRM оригинала и его аналитика отключены. Валидация обязательных полей, телефонная маска, выбор комнат и согласие используют оригинальные компоненты. Папка `data/` не раздаётся веб-сервером и исключена из Git.

Появление элементов при прокрутке занимает 0,85 секунды без задержки, со сдвигом до 24 px. `IntersectionObserver` запускает его внутри видимой области: с отступом 24 px от нижней границы и 64 px под закреплённым заголовком. Отдельный наблюдатель сбрасывает элемент только после полного выхода за экран с запасом 96 px, чтобы повторять при возвращении без мерцания на границах. Поздно созданные элементы слайдеров тоже подключаются. При `prefers-reduced-motion: reduce` или отсутствии `IntersectionObserver` содержимое показывается сразу. Интерактивные hover-эффекты и фоновые SBS-анимации Tilda сохраняются.

Кнопка «Наверх» появляется в нижнем левом углу после прокрутки и плавно возвращает к началу страницы. При уменьшении движения в системных настройках прокрутка выполняется без анимации. Локальные стили после маркера `LOCAL APPEARANCE OVERRIDES` сохраняются при повторном запуске загрузчика.

Семь «+» в блоке фасадов открывают карточки с иллюстрацией, коротким объяснением и преимуществом решения. На компьютере доступны наведение и нажатие, на телефоне — нажатие. Карточка остаётся открытой при переходе указателя на неё, закрывается крестиком, повторным нажатием, нажатием вне неё или Escape. Клавиатура: Tab открывает описание при фокусе на точке, Enter закрепляет, ArrowDown переводит фокус на кнопку закрытия; после закрытия фокус возвращается к точке. Положение учитывает границы экрана и закреплённую шапку. Русская и казахская страницы используют общую логику `materialCards()` в `local-runtime.js`.

Иллюстрации в `assets/images/materials/` созданы встроенным image_gen и сохранены как небольшие JPEG. Это примеры материалов и решений; на карточках есть соответствующая подпись. Полные запросы и исходные пути сохранены в `scripts/image-prompts/material-cards.json`. Описания используют состав материалов из оригинальной страницы; общие свойства сверены с [Xella](https://www.xella.com/en_US/who-we-are-xella-in-portrait), [Schüco](https://www.schueco.com/de-en/architects/products/facades?123946=true) и [Arup](https://www.arup.com/en-us/services/lighting-design/). Марки производителей и численные показатели этих продуктов не заявляются для SAF Avenue.

## Проверка и сборка

При работающем сервере:

```sh
npm run check
npm run build
```

`check` проверяет страницы, доступность всех сохранённых ресурсов, корректность файлов шрифтов, отклонение неполных заявок и недоступность внутренних файлов через HTTP. В браузере проверены русская и казахская версии, настольное и мобильное отображение, меню, буклеты, вкладки планировок, увеличение планировок, валидация и локальное сохранение заявки.

Регрессионные проверки:

```sh
npm test
npm run test:mirror
```

`test` запускает отдельные серверы на свободных портах и проверяет обход путей Windows, некорректные URL, казахскую политику, неверные и слишком большие заявки и прерванную загрузку формы. Также проверяются сборка Agentation, подключение ко всем страницам в dev-режиме, приоритет `NODE_ENV=production` и отсутствие панели и её зависимостей в статической сборке. `test:mirror` использует Python из стандартного окружения, работает без сети и проверяет точную замену URL, HTML-сущности и сохранение опубликованных страниц при ошибках скачивания.

Загрузчик останавливается с ошибкой при неполном скачивании, записывает причину в `mirror-errors.json` и сохраняет прежние страницы. URL заменяются только при точном совпадении с существующим локальным ресурсом; запись для корня CDN в манифест не включается. Пользовательская панорама сохраняется при повторном запуске загрузчика.

`build` формирует `dist/` с готовой статической копией, включая маршруты в виде папок с `index.html`. Для сохранения заявок нужен обработчик `/api/leads` из Node-сервера или подключение собственного серверного обработчика.
